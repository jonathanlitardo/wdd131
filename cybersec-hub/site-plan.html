WDD 131-A1

Overview

Purpose

Cybersec Hub provides interactive cybersecurity learning tools and resources for students and beginners. Through hands-on demonstrations like password strength analysis, security tools exploration, and interactive quizzes, this site will make complex security concepts accessible accessible and practical for those entering the cybersecurity field.

Audience

The primary audience includes cybersecurity and IT students (like BYU-Idaho students), beginners interested in security careers, and those preparing for certifications like Security+. The audience is tech-comfortable but seeks practical, interactive ways to understand and apply security principles beyond textbook learning.

Dynamic elements

  1. Password Strength Analyzer (Home Page)
    • Input field for password
    • Real-time strength indicator
  2. Interactive CIA Triad quiz/game
    • Multiple-choice questions
    • Correct/incorrect feedback
  3. Network visualization showing attack types (phishing, DDoS, MITM)
    • Interactive visualization
    • Attack type explanations
  4. Searchable database of security tools you've used (Wireshark, Nmap, etc.)
    • Searchable database
    • Tool descriptions
    • Tool usage examples
